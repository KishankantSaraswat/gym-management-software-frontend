# GymHood Admin

A React and Tailwind CSS starter built with Vite and TypeScript.

## Getting started

Requires Node.js 20.19 or newer.

```sh
npm install
npm run dev
```

## Scripts

- `npm run dev` starts the development server.
- `npm run build` type-checks and builds the production app.
- `npm run preview` serves the production build locally.

Tailwind styles are processed through PostCSS. Add source paths to
`tailwind.config.js` if you add files outside `src/` or `index.html`.
